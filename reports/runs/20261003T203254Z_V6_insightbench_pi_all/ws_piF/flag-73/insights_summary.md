# Asset Cost vs Warranty Analysis Insights

## Key Findings

1. **Weak Negative Correlation**: There is a weak negative correlation (-0.138) between asset cost and warranty period, suggesting that higher-cost assets don't necessarily have longer warranties.

2. **Average Asset Characteristics**: On average, hardware assets cost $3,124 with an average warranty period of 585 days.

3. **Cost vs Warranty Discrepancies**: 
   - High-cost assets (top 25%) have an average warranty of 566 days, which is shorter than the overall average
   - Assets with high cost but low warranty (e.g., P1000134 with $4,971 cost and 90-day warranty) represent procurement discrepancies

4. **Asset Category Differences**:
   - Computer category has the shortest average warranty (363 days) compared to other asset types
   - Server and Storage Device categories have the longest average warranties (816 and 794 days respectively)

5. **Department Variations**:
   - Development department has the longest average warranty (638 days) among all departments
   - IT department has the shortest average warranty (544 days)

6. **Procurement Strategy Issues**:
   - Some high-value assets like P1000228 ($11,516) have only 366-day warranties, indicating potential procurement misalignment
   - Several assets with costs exceeding $4,000 have warranty periods under 100 days

These insights suggest that procurement strategies should be aligned with warranty expectations to ensure appropriate value for money and reduce risk exposure.
